【一、 安装与启动】
1. 将压缩包内的 cry.exe 和 install.bat 放在同一文件夹中。
2. 双击运行 install.bat，等待提示“安装成功”。
3. 按下 Win+R 键，输入 cmd 回车打开终端（或打开 PowerShell）。
4. 在任意目录下输入 cry 并回车，即可启动 Cry Shell。
5. 启动后，你会看到 cry> 提示符，此时即可输入指令。


【二、 指令大全】
说明：所有指令均支持中英文双语，大小写不敏感。输入内置指令后按回车执行。
      如果输入非内置指令（如 git status），将自动透传给系统执行。

[基础控制]
  q / 退出               退出 Cry Shell
  cls / 清屏             清空当前终端屏幕
  help / 帮助            查看所有指令及简要说明

[开发环境探针]
  env / 环境             极速并发扫描所有常用语言环境，输出状态表格

[系统监控与进程控制]
  sys / 状态             实时概览：CPU、内存、交换空间占用
  ps / 进程              查看占用内存最高的前15个进程列表
  kill <pid> / 杀 <pid>  快速杀死指定进程 ID 的进程 (示例: kill 1234)

[快捷启动应用]
  run <name> / 启动 <名字>  模糊搜索本地应用并后台启动 (示例: run chr 启动 Chrome)
  scan / 扫描应用           重新扫描系统已安装应用，更新本地缓存

[高速下载引擎 (支持 8 线程并发)]
  dl <url> / 下载 <链接>          提交 HTTP 链接到后台极速下载 (示例: dl https://...)
  dls / 下载列表                 查看所有下载任务的实时状态、进度条和百分比
  dlpath [path] / 下载路径 [路径] 设置/查看下载保存目录 (示例: dlpath D:\Downloads)

[网络侦察与渗透]
  scan_port <ip> <ports> / 扫描端口 <ip> <端口>  极速并发 TCP 端口扫描 (示例: 扫描端口 127.0.0.1 1-1000)
  ping_scan <cidr> / 存活扫描 <网段>           并发 TCP 探测局域网存活主机 (示例: 存活扫描 192.168.1.0/24)
  banner <ip> <port> / 指纹 <ip> <端口>        抓取目标端口的服务指纹 (示例: 指纹 127.0.0.1 80)
  http_probe <url> / 探针 <url>               提取 HTTP 状态码及安全响应头 (示例: 探针 example.com)
  sniff [iface] / 抓包 [网卡]                 调用系统底层工具抓取网络数据包 (示例: 抓包)

[极客工具箱]
  serve [port] / 共享 [端口]           启动 HTTP 静态文件服务器，支持局域网下载本机文件 (示例: 共享 8000)
  hash <file> <algo> / 哈希 <文件> <算法> 计算文件的 MD5 或 SHA256 校验值 (示例: 哈希 test.txt sha256)

[AI 智能体终端 (内置 ReAct 工具调用)]
  agent / 代理                 进入 AI 模式（提示符变为 ai>）

  --- AI 模式下专属指令 ---
  set api <key> <name> / 设置 密钥 <key> <name>  保存一个 API 密钥并自定义命名 (示例: set api sk-xxx my_key)
  list models <name> / 列出 模型 <name>       获取指定名称密钥下的可用模型列表 (示例: list models my_key)
  use <model> / 使用 <model>                 选择当前要使用的 AI 模型 (示例: use gpt-4o-mini)
  exit / back / 退出 / 返回                  退出 AI 模式，回到主 Shell (cry>)
  (直接输入文本)                             AI 将自动判断是否调用本地工具并执行 (示例: 帮我看看127.0.0.1开了什么端口)


【三、 常见问题】

Q: 为什么我输入指令后提示“不是内部或外部命令”？
A: 这通常是因为复制粘贴时带入了不可见字符。请尽量手动输入前几个字母，然后按 Tab 键自动补全，或按右方向键 -> 接受灰色提示。

Q: 下载的文件保存在哪里了？
A: 默认保存在系统的“下载”文件夹中。你可以使用 dlpath 指令修改保存路径，例如：dlpath D:\MyFiles

Q: 使用 AI 功能需要什么？
A: 需要一个兼容 OpenAI 格式的 API Key。进入 AI 模式后，使用 set api 指令保存密钥，然后使用 use 指令选择模型即可对话。AI 可以自动帮你执行扫描端口、查看系统状态等操作。
